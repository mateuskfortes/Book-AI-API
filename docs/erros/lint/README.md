# Erros de lint

Esta pasta separa falhas de qualidade do backend e do frontend.

- [Backend](backend/README.md): KtLint e Detekt executados por `./gradlew lint`.
- [Frontend](frontend/README.md): ESLint executado por `cd frontend && npm run lint`.

Consulte a categoria correspondente antes de corrigir uma nova falha. Se o erro envolver mais de uma área, registre-o na categoria da causa principal e liste as demais áreas no campo de impacto.
