# Erros de lint do frontend

O lint do frontend é executado por `cd frontend && npm run lint`, usando ESLint com configuração flat em `frontend/eslint.config.js`.

Ao corrigir uma falha, altere a fonte em `frontend/src` ou a configuração do Vite. Não edite diretamente os arquivos gerados em `src/main/resources/static`.
