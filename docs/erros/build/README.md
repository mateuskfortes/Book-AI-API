# Erros de build

Esta pasta registra falhas de compilação, empacotamento Gradle, build do Vite integrado ao Docker e problemas de dependências que impedem gerar o artefato da aplicação.

Ao investigar um erro, consulte primeiro [o índice geral](../README.md) e depois pesquise nesta pasta pela mensagem, tarefa Gradle ou ferramenta envolvida.

## Registro de novos erros

Crie um arquivo com nome descritivo em `kebab-case.md`. Inclua comando, mensagem sem segredos, causa, solução, arquivos afetados e verificação. Atualize o índice desta pasta quando o volume de registros justificar uma lista própria.
